# UI/UX Pro Max - AI-Powered Design Intelligence (UUPM)

This skill integrates design principles and styling instructions from UI/UX Pro Max (https://www.uupm.cc) into the workspace. It outlines the core guidelines to create highly aesthetic, professionally crafted interfaces.

## 1. Core Guidelines

- **High Contrast Contrast-Ratios**: Ensure clean typography and deep readability. Headings should pop out against pure background using fine-tuned opacities and subtle text-shadows.
- **Fluid & Responsive Motion**: All page transitions, hover states, and canvas resizes should use highly optimized spring physics.
- **Dimensionality (The Parallax Prism)**: Use layering, deep 3D-perspective-transformations, and cursor-sensitive parallax offsets on main UI cards.
- **Holographic Glassmorphism**: For modern elements like badges and cards, combine `backdrop-blur-xl` and nested glowing shadows.

## 2. Interactive Features

- **Magnetic Links & Buttons**: When the cursor hovers near navigation links or primary actions, the element should subtly snap to the pointer using spring values.
- **Dynamic Spotlight Tracking**: Real-time position tracking generates a smooth light glow tracking the cursor behind cards, avoiding static hover states.
- **Noise Background Mesh**: A premium grain/noise texture mask adds organic material quality to the dark space backgrounds.
